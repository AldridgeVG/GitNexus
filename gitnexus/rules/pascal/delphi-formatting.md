# Delphi 排版格式规范

编写 Delphi 代码时必须遵循以下排版格式。

## 缩进

- 使用**空格**缩进，不使用制表符
- 每级缩进 **2 个空格**
- 顶格元素：`unit`, `interface`, `uses`, `implementation`, 文件结尾的 `end.`
- 遇到 `begin` 增加一级缩进，遇到 `end` 减少一级缩进
- 进入判断、循环、异常处理、with、类型声明时增加一级缩进

## 空格

- 操作符和逻辑判断符两端加空格：`I := I + 1;`、`if (A <> B)`
- 括号内侧不加空格：`CallProc(A);`、`List.Items[3]`
- 冒号左侧无空格，右侧加空格：`V: Integer;`
- 逗号/分号左侧无空格，逗号右侧有空格：`Proc(A, B);`
- REGION 名称引号内前后加空格：`{$REGION ' TMyClass '}`

## 空行

- 不同逻辑/语义/业务的代码之间插入一个空行
- 函数前后、类型声明前后、interface/implementation 前后各空一行
- REGION 前后空一行

## 换行

- 单行不超过 **120** 个字符（含注释）
- 超长行在逗号/分号之后或 `and`/`or` 之后换行，换行后缩进两格
- `if...then` / `else` 独占一行（`else if` 除外）
- `begin` / `end` 独占一行
- **一行只写一条语句**，禁止多语句写在同一行
