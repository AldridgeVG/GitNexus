# Delphi 注释规范

编写 Delphi 代码时必须遵循以下注释规则。

## 必须添加注释的场景

- **接口类（interface）** 的所有函数、变量、属性必须有注释
- **类的 public / protected** 部分的函数、变量、属性必须有注释（默认构造/析构除外）
- **所有抽象方法**（interface 方法、abstract 方法、设计为被重写的 virtual 方法）需注明：
  - 方法用途
  - 参数含义及数据范围
  - 返回值含义
  - 错误码 / 是否抛出异常
  - 实现/重写规范（若为基类/接口）
- **所有枚举值**必须有注释说明含义和用途
- **超过 20 行的函数**必须有行间注释解释过程逻辑
- 函数参数应注明含义、数据范围、范围检查未通过时的处理方式
- 返回值应注明不同返回值含义及调用者是否需额外处理

## 注释原则

- 注释说明**为什么**（Why），而非对代码的字面翻译
- 维护代码时**必须同步维护注释**，删除无用注释
- 废弃代码直接删除，不要注释掉；暂时排除的代码用 `// TODO:` 标记
- 注释语言统一使用中文
- 建议 private 部分也添加注释

## TODO 格式

```pascal
// TODO -o{NAME} -c{CATA}: 描述内容
```

- `-o{NAME}`：姓名缩写
- `-c{CATA}`：类别关键字
